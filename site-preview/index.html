Build a company. Let AI run it.

Mero turns an idea into a real business: a brand, a structurally-editable website, and an AI workforce with explicit permissions that operates the company under the owner's supervision.

This page is a static screenshot preview, not the live app. Mero is a full server application — real login, a real database, and dozens of API routes that do real work (AI generation, task execution, approvals). GitHub Pages only serves static files, so it structurally cannot run any of that. What follows are real screenshots from an actual running instance, walking through the product end to end.

Want to actually use it?

  1. Clone the repo and check out claude/wizardly-noether-ydvfj2
  2. npm install
  3. cp .env.example .env and fill in DATABASE_URL / AUTH_SECRET (optionally ANTHROPIC_API_KEY for real AI generation)
  4. npx prisma migrate dev
  5. npm run dev — open http://localhost:3000
